# Gestion des comptes

Pour réinitialiser un mot de passe oublié, sélectionne « Mot de passe oublié » sur le portail de connexion interne et valide ton identité avec ta méthode de récupération enregistrée. Une fois le mot de passe changé, reconnecte tes applications professionnelles.

Si tu n'as plus accès à ta méthode de récupération, contacte le support IT par téléphone pour une vérification d'identité. Ne communique jamais ton mot de passe ni ton code multifacteur.
